# 🎉 Event Management Dashboard

A responsive and interactive **Event Management Dashboard** built using **ReactJS**.
This project allows users to manage events and participant registrations with a clean UI and dynamic functionality.

---

## 🚀 Features

### 📊 Dashboard

* View summary cards:

  * Total Events
  * Upcoming Events
  * Completed Events
  * Total Participants

### 📅 Events Module

* Add new events
* Delete events
* Mark events as completed
* Dynamic rendering using `.map()`
* Event details include:

  * Event Name
  * Date
  * Venue
  * Organizer Name
  * Status

### 👥 Participant Module

* Add participants for events
* Delete participant entries
* Dynamic participant list rendering
* Participant details include:

  * Name
  * Email
  * Event Name

### 🔗 Navigation & Routing

* React Router implementation
* Multi-page navigation
* Responsive Navigation Bar

### 🎨 UI & Styling

* Responsive design
* Modern cards and tables
* Clean user interface using CSS

# ⚙️ Installation & Setup

## Clone the Repository

```bash
git clone https://github.com/Ok-anant/FSD_Makeup.git
```

## Navigate to Project Folder

```bash
cd FSD_Makeup
```

## Install Dependencies

```bash
npm install
```

## Run the Development Server

```bash
npm run dev
```
